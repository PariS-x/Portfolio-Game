# Signal Quest — Interactive Portfolio

An interactive, game-based portfolio where users explore my work through a retro space mission.

Instead of scrolling through a traditional website, users navigate sectors, recover signals, and unlock information about my projects, experience, and education.

## Concept

Traditional portfolios are static and linear.

Signal Quest reimagines a portfolio as an interactive system:
- The user starts in a “lost signal” scenario
- Each sector represents a part of my profile
- Information is revealed through interaction and exploration

---

## Tech Stack

- HTML5 Canvas
- JavaScript (Vanilla)
- Custom rendering logic
- Game loop and state management
- Event-driven input handling

---

## Features

- Retro pixel-style interface
- Multi-room navigation system
- Signal-based progression mechanic
- Terminal-style data viewer
- Dialogue system for guided interaction
- Keyboard and touch controls

---

## Architecture Overview

The project is designed as a lightweight game engine:

- Rendering Layer: Canvas-based tile system
- State Manager: Controls screens, transitions, and progression
- Input System: Handles keyboard and touch interaction
- Data Layer: Structured representation of portfolio content
- UI Systems: Dialogue engine, terminal interface, HUD
